# HR-214: Probation Ending Soon — Alert in Directory

**Raised by:** Emma Walsh, HR Manager
**Date:** 2 weeks ago
**Priority:** Medium

## Request

We keep missing probation review windows. By the time a manager notices an employee is still showing as "Probation" in the directory, the 90-day window has already closed and we've missed the formal review.

We'd like some kind of visual indicator in the employee directory that flags when a probation period is ending soon — something the manager can see at a glance when they're looking at the team list.

It doesn't need to be complicated. Just something that catches the eye before it's too late.

## Context

- Probation periods are tracked per-employee via the `probationEndDate` field
- Not all employees have a probation period (contractors, interns, returning hires)
- "Soon" is roughly manager judgement — could be 2 weeks, could be a month

## Out of scope

Automated emails, calendar integrations, or changes to the leave system.
